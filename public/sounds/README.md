# Spin sound (3 seconds)

To enable the wheel spin sound:

1. Download the **Film Special Effects Spin** sound from Pixabay:  
   https://pixabay.com/sound-effects/film-special-effects-spin-232536/
2. Save the MP3 in this folder as **`spin.mp3`**.

The wheel animation is 3 seconds so it stays in sync with the sound.  
If `spin.mp3` is missing, the app still works without sound.
